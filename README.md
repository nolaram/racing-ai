# Racing AI

## Project Overview

Racing AI is a 2D racing game developed using Python and Pygame. The project aims to explore reinforcement learning by training an AI controlled car to drive independently, navigate racetracks, and eventually perform controlled drifting.

## Project Goals

- Develop a functional 2D racing environment.
- Train an AI agent to drive autonomously.
- Teach the AI to navigate corners and avoid obstacles.
- Explore reinforcement learning techniques to improve driving performance.
- Implement drifting mechanics and train the AI to use them effectively.
